# Aoife GP Practice Data Management with R

## Overview

This repository contains an R-based data management and analytics project developed for **Aoife's GP Practice**. The project demonstrates how R and RStudio can be used to improve administrative efficiency, automate reporting, and support data-driven decision-making within a general practice.

The report examines the current challenges faced by the practice, including fragmented data storage, manual reporting processes, and increasing administrative workloads, before proposing practical solutions using the R programming language.

---

## Project Objectives

* Improve data organisation and accessibility
* Automate repetitive administrative tasks
* Generate consistent and accurate reports
* Support evidence-based decision-making
